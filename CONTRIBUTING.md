# Contributing to Mallside

Mallside is a proprietary, source-available game maintained by [YouKnowJP](https://github.com/YouKnowJP). Public source access does not grant commercial reuse rights. Read the [permissions guide](PERMISSIONS.md), [LICENSE](LICENSE) and [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) first. A GitHub fork or submitted pull request does not authorize a public game host, commercial distribution or relicensing of existing Mallside material.

Bug reports and gameplay feedback are welcome through GitHub Issues. Include the browser/device, game version, clear reproduction steps, expected result and actual result. Screenshots help; remove private information. Do not upload a complete save unless the maintainer requests a safe, reviewed example.

Discuss code or asset contributions with the maintainer before opening a pull request. Any contribution needs an agreed written permission arrangement before acceptance; opening a PR is not treated as an assignment of your rights or a license to unrelated material. Do not submit scraped images, brand artwork, personal data or code whose rights you cannot establish. Do not introduce new third-party licenses without documenting them.

For agreed changes, use a feature branch, keep the scope focused, run `npm run check` and `npm test`, and include relevant QA notes. Do not change catalog prices, ownership rules or saved-state formats incidentally. Use only fictional game purchases during testing. See [architecture](docs/ARCHITECTURE.md) and [deployment](docs/DEPLOYMENT.md).
