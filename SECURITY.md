# Security and responsible reports

Mallside is a static browser game with local saves. It does not require payments, real retailer credentials or API keys. Never place tokens, private save files, environment files or account data in the repository or a public issue.

For routine gameplay bugs, use the bug-report template. For a vulnerability that could expose private data or execute unexpected code, use GitHub's **Security → Report a vulnerability** if that private channel is available. Otherwise contact [the maintainer](https://github.com/YouKnowJP) to arrange a private channel before sharing exploit details. Do not publish a working exploit or anyone else's data in an issue.

The maintainer reviews the current `main` release; there is no promised support period or response-time SLA. Third-party library reports should also follow the relevant upstream project's security process. Security fixes must preserve asset notices and be checked before deployment.
