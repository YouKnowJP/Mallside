# Mall map references — v6

Research checked October 26, 2026. The game uses original vector schematics, not copies of map artwork. These maps are **not exact replicas or current navigation maps**. Major wings, landmarks and anchor relationships informed the graphs; concourse shapes, distances, floor footprints, elevator placement and shop/service pins are adapted for gameplay. All playable floor views currently share each center's simplified graph. Real centers may have smaller, disconnected or tenant-only upper floors.

No real tenant inventory or affiliation is implied. A brand can appear at a curated game location even where it does not lease a real unit. Every Guide includes the reference link and accuracy disclosure.
