# Whole-center map expansion — v10

Checked October 27, 2026. This update replaces the small shared 3D courtyard with complete-center circulation models and directory coverage. It does not claim measured architectural replicas or current real-world navigation. Original geometry represents the principal wings and connections; storefront rectangles and distances are condensed. The bundle contains 1,598 retained directory entries. Real directory names and explicit floor/section facts are retained. Unknown floor placements are labeled as game placements.

`dist/full-center-data.js` contains factual names, source metadata, explicit floor/zone facts and source notes. The research inputs were transcribed from official public records; no store descriptions, logos, photos or operator map artwork were copied into the new scenery. Existing product photos remain separately documented.

All 23 playable views support wide-area floor movement, physical building collision, floor-aware automatic routes and a whole-center planner. The game’s original activities and catalog counters remain adaptations; a real directory storefront does not imply playable stock, real current prices or affiliation.
