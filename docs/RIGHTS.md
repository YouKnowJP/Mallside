## What the project reserves

[LICENSE](../LICENSE) is a proprietary license. It grants personal non-commercial play and private evaluation, while reserving commercial reuse, distribution and hosted copies of protected Mallside material. It does not use MIT, Apache or an open-source label for the game. A notice is also shipped in the playable site, so the terms do not exist only in GitHub documentation.

The reservation applies only to copyrightable expression the owner actually owns. It does not create rights in shopping as an idea, game mechanics, facts, public-domain material, independent third-party assets or solely AI-generated expression that lacks copyright protection under applicable law. The project was developed with AI assistance. This repository does not establish the human-authorship or ownership status of every file. Preserve records of human design, writing, selection, arrangement and revisions; obtain professional advice about registration, claims and any exclusions.

## What it cannot prevent

While a repository is public, it permits reading/downloading, and GitHub's terms permit viewing and forking there. A browser must receive game code and assets to play a static game. The proprietary notice expresses the owner's permissions and can support a rights claim where valid; it is not DRM, an enforcement service or a promise that nobody can copy or profit. Keeping future source private can reduce exposure but cannot make delivered browser assets secret. The source repository was made private on 28 October 2026. Only generated browser files are published; earlier public downloads or forks cannot be recalled.

The original GitHub starter commit had an MIT notice and README only. No game files were present. That history remains intact. The new game import is accompanied by its own license. Existing valid rights in material previously distributed under another license cannot be withdrawn by adding this notice; no such withdrawal is claimed. See [migration provenance](MIGRATION.md).

## If copying is discovered

Preserve dated evidence, URLs, commits and the exact allegedly copied original expression. Separate owned work from public-domain/library/brand assets. Confirm ownership and any existing permissions, then consult qualified IP counsel about the appropriate response. This repository does not file registrations, register a trademark, send demands or submit takedowns. Do not claim a registered copyright or trademark without a completed registration.
