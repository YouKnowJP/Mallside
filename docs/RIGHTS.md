## What the project reserves

[LICENSE](../LICENSE) version 1.1 is a proprietary license. It grants free personal non-commercial play, private evaluation and non-commercial gameplay media, while reserving commercial reuse, distribution and hosted copies of protected Mallside material. The [permissions guide](../PERMISSIONS.md) gives practical examples and the official play link. Rebranding, credit, a free mirror or fundraising tied to a clone does not itself grant permission. It does not use MIT, Apache or an open-source label for the game. A notice is also shipped in the playable site, so the terms do not exist only in GitHub documentation.

The reservation applies only to copyrightable expression the owner actually owns. It does not create rights in shopping as an idea, game mechanics, facts, public-domain material, independent third-party assets or solely AI-generated expression that lacks copyright protection under applicable law. The project was developed with AI assistance. This repository does not establish the human-authorship or ownership status of every file. Preserve records of human design, writing, selection, arrangement and revisions; obtain professional advice about registration, claims and any exclusions.

## What it cannot prevent

While a repository is public, it permits reading/downloading, and GitHub's terms permit viewing and forking there. A browser must receive game code and assets to play a static game. The proprietary notice expresses the owner's permissions and can support a rights claim where valid; it is not DRM, an enforcement service or a promise that nobody can copy or profit. Keeping future source private can reduce exposure but cannot make delivered browser assets secret. The source repository was temporarily made private on 28 October 2026. The owner then chose public source and direct free GitHub Pages hosting in one repository. The playable site uses optimized generated files; the editable source and Git history are publicly readable. Earlier downloads or forks cannot be recalled.

The original GitHub starter commit had an MIT notice and README only. No game files were present. That history remains intact. The new game import is accompanied by its own license. Existing valid rights in material previously distributed under another license cannot be withdrawn by adding this notice; no such withdrawal is claimed. See [migration provenance](MIGRATION.md).

## Keeping the policy effective

The current license and permissions guide ship with the playable artifact, and generated JavaScript retains a clearly scoped ownership notice. The release metadata names the license, guide and official play URL. Source/artifact checks reject mismatched notices or a missing bundle notice. The provided workflow only uploads/deploys Pages from the canonical `YouKnowJP/Mallside` repository; forks can still run checks. This reduces accidental publication through an unchanged fork workflow. A person can edit copied code or workflows, so these are attribution and release-integrity measures, not technical copy protection. Player access remains free and account-free.

Keep dated commits, source releases, human-authored design/revision notes, contribution agreements and asset provenance. Record any separate written permission with its scope and the material/version covered. Review code/asset contributions before merging; a PR is not an ownership assignment. A notice change cannot recover missing third-party rights or cancel a valid earlier grant.

The owner can have qualified IP counsel review the custom license, human-authorship evidence and a possible copyright registration for eligible material. No filing, fee, registration, trademark application or legal demand is performed by this update.

## If copying is discovered

Reports can use the repository’s [permission/rights issue form](https://github.com/YouKnowJP/Mallside/issues/new/choose); keep private documents out of public issues. Preserve dated evidence, URLs, commits and the exact allegedly copied original expression. Separate owned work from public-domain/library/brand assets. Confirm ownership and any existing permissions, then consult qualified IP counsel about the appropriate response. This repository does not file registrations, register a trademark, send demands or submit takedowns. Do not claim a registered copyright or trademark without a completed registration.
