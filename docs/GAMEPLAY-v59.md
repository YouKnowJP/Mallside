# Mallside v59 · a visit worth slowing down for

Reviewed 5 November 2026. This update connects original planning rooms and public seating to usable shopping choices. It preserves the distinction between verified merchandise and research-only shops.

## Compare materials together

In any of the 292 unfinished retail planning lounges, open the material study and choose **Preview with the host on the shop floor**. The dialog closes so the workbench and people remain visible. Choose a palette and finish in the controls below the scene while the host walks from the help point to a clear position beside the workbench. The host uses the existing browsing gestures beside the samples. Material colors and surface finishes ease into the new selection.

**Keep study · free** stores the existing material note at this shop. **Cancel preview** restores the saved note and sends the host back continuously from their current position. Leaving the shop, rebuilding the view, changing graphics or entering recovery clears the temporary consultation. Other dialogs pause the host and preserve the draft. Ordinary game time continues while the floor is active. Saving a note charges no fee, reserves no stock and awards no XP.

Reduced motion keeps the host at the help point with the same usable controls and immediate material changes. Lighter graphics retains the existing accessible material dialog. Palette controls keep their DOM identity during changes, so native select navigation proceeds to the next control without replacing the focused input. Fullscreen and compact views retain the scene, 44 px controls and clear save/cancel choices.

Task lamps, colored paper tabs, framed samples and finer original workbench construction give those existing footprints a clearer purpose. These creative samples remain original game props and never become merchandise.

## Pause, review and choose

Public mall benches gain restrained original arm caps, fasteners and planning plaques within their existing footprints. Their **Pause & plan** guide shows actual unpaid picks, saved shortlists and up to four closest stocked shops on the current game floor. Each destination uses its real game route. A floor without stocked collections offers a clear map option instead. Reviewing is free; resting uses the existing 30-minute recovery rule. The bench guide avoids repeating the general lounge destination list.

Associate walking now eases into motion and slows near route points. Existing selected-size checks, cancellation, shopper separation, fitting, checkout, refunds and shop exits retain their rules.
