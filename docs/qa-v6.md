# Mallside 6.0.5 validation

October 26, 2026. Local preview served only from `dist` at port 4317. Browser checks used the normal UI, separate local free-shop saves, and read-only DOM observations. No real transactions occur.

## Automated

`npm test`: **122 passed, 0 failed**, including:

- Every one of 548 listings: inspect, fit or demo, checkout, applicable return, use and reload.
- A complete 24-chapter earned-income career; 2,000 deterministic economy actions; existing purchase, refund, package, request, equipment and sleep invariants.
- All ten new map graphs connected and non-linear; every shop door, service, landmark, elevator and exit reachable on all twenty floor views. Samples along every generated route remain inside walkable concourses.
- 20,000 seeded keyboard moves stay within walkable geometry.
- Valid and invalid floor changes, once-only landmark/trail rewards, reload persistence and v5 migration.
- All 65 additions have positive integer-cent prices, primary source URLs, named model identities and reference dates. This is a structural test, not independent real-time price verification.

- Captured console warning/error lists were empty during the final local map checks.

## Limits

Not tested on physical iPhone/iPad hardware or Safari/Firefox this release. Responsive viewport tests do not certify every browser/device. No claim that the software has zero bugs. Maps deliberately remain schematic major-wing recreations; floor footprints and curated tenant/service pins are not exact current mall plans. New LEGO reference prices are historical Spring 2024 prices, not claims of current stock or current retail prices. Other game catalog prices and availability remain simulated where no dated source price is displayed.
