# v34 — useful corners and shop guides

Every public floor now has a water refill station and a community noticeboard: 46 new physical stops across the 23 floor views. Find them in **Map → Things to do on this floor**, walk up to the fixture, or select its nearby prompt. Water keeps the existing free three-minute drink and 30-minute cooldown. Noticeboards use the existing original invitations and daily reward limit. The discovery notebook and all three original public activities remain available.

Seated readers and resting visitors bring life to court benches. Crowd preferences also control these visitors. New fixtures use original paper, timber, metal and planting details; the illustrated fallback includes recognizable water and notice symbols.

Research-only shops now have an information gallery and useful options:

- **Collection guide** explains the current availability and links to verified collections at the same center.
- **Save this shop** keeps the location in **Shops → Saved shops**. A direct shortcut shows the saved count for this center and supports touch and Enter activation. The list holds up to 80 places per save mode; the same button removes one. It does not spend money or reserve products.
- **Meet the associate** walks to the actual host. **Find stocked shops** opens the searchable ready-to-shop directory.
- A pinned **Exit shop → Mall** footer stays available while the guide scrolls, including narrow screens.
- Fitting, department and checkout controls in these locations now lead to collection information and associate help instead of empty product screens. Stocked and service shops retain their fitting, buying, returns and booking flows.

Walking poses ease between moving and standing while releasing input still stops the player's position immediately. Browsing, comparing, paying and conversation poses use distinct arm/head gestures. Reduced motion keeps gestures static, and the collection-room walk preview uses the same easing.

Existing saves remain version 6, with the same primary and backup keys. Older saves receive an empty saved-shop list. The update adds no fictional retail products and does not expand the researched catalog.
